# -1- Лабораторная работа 3 на тему "Оценка эффективности системы ПРО методом Монте-Карло". Описание кода.
Код был написал с использованием библиотек:

	Numpy - для быстрой генерации случайных чисел и векторных вычислений над массивами;
	Matplotlib - для визуализации результатов.
	
Программа состоит из одной функции run_simulation(), которая выполняет все этапы: генерацию, расчёт, визуализацию и вывод результатов.
Метод Монте-Карло

	Суть метода: вместо аналитического расчёта сложных вероятностей мы многократно «разыгрываем» случайный сценарий (падение ракеты) и считаем долю исходов, удовлетворяющих условию. При больших N доля стремится к истинной вероятности.
Формула оценки вероятности события А:

													P(A)=1/N ∑_(i=1)^N〖ΙΙ(A_i ),〗
													
где  ΙΙ(A_i )=1, если событие произошло на i-ом испытании
Основные вычисления

Все вычисления в программе сводятся к нескольким ключевым величинам, которые оцениваются по выборке из N случайных точек.

	Расстояние от точки падения до центра города
		Для каждой i-й ракеты вычисляется евклидово расстояние от точки падения до центра города:
			d_center = np.sqrt((fall_x - Cc)**2 + (fall_y - Cc)**2)	
	где x_i,y_i-координаты точки падения,C_c-координата центра города.
	Вероятность попадания
			P_city = np.mean(in_city)
	Вероятность прорыва через ПРО
			P_leak = np.mean(~is_intercepted)
	Статистическая погрешность 
			ε=√((P(1-P))/N),
	где P – вероятность, N – число испытаний. 
# -2- Физическая модель
Постановка задачи
	Город – квадратная зона со стороной R_c=100 км. На город летит баллистическая ракета. Система ПРО пытается её перехватить.
Допущения модели:
	- Точка падения ракеты описывается двумерным нормальным распределением с центром в центре города и стандартным отклонением σ=15 км по каждой оси.
	- Система ПРО гарантированно перехватывает ракету, если точка падения попадает в круг R_p=10 км радиуса вокруг центра.
	- Радиус поражения ракеты R_k=25 км используется для визуализации, но в расчёте вероятностей не участвует - ущерб считается бинарным.
Ограничения модели
	- Не учитывается время полёта и динамика ракеты.
    - ПРО имеет детерминированную зону перехвата.
    - Ущерб бинарный: либо «попала в город», либо нет. Не учитывается частичное поражение.
# -3- Валидация модели
Способы валидации
	Аналитическая проверка:
		- При σ⟶0 (идеальное наведение)  P_city⟶1,P_leak⟶1-(π〖R_p〗^2)/〖R_c〗^2 .
		- При σ⟶∞ (полный хаос)  P_city⟶0,P_leak⟶1.
	Проверка закона больших чисел:
		При увеличении N_SIM оценка вероятности стабилизируется. 
	Визуальная проверка:
		Тепловая карта и гистрограмма показывают распределение, близкое к гауссову.
# -4- Параметры запуска
Исходные данные:
	1)	Rc = 100.0 - размер города (City Radius/Size)
	2)	Cc = Rc / 2.0 - центр города (City Center)
	3)	S  = 15.0 - разброс наведения (Sigma)
	4)	Rk = 25.0 - радиус поражения ракеты (Kill Radius)
	5)	Rp = 10.0 - радиус зоны перехвата ПРО (Protection Radius)
	6)	N_SIM = 500000 - количество испытаний Монте-Карло
	7)	N_VIS = 8000 - точки для визуализации
